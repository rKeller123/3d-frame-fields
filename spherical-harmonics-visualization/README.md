
This folder includes 3 mini-applications to view the frames in the browser.

## Octahedral
This app visualizes the octahedral frames.

## Odeco
This app visualizes the odeco frames.

## Projection
In this app, odeco frames are visualized also. However, the input data (either angles and scaling ratios OR individual coordinates) are sent to a C++ application which computes the projected odeco frame. For this to work, the executable `cli.exe` must be located inside of `3d-odeco-frame-fields/out/build/x64-debug`.
